Arquitectura general

todo en red local, sin depender de la nube

La web vive en un pequeño servidor del aula (mini-PC o Raspberry Pi) y habla directamente con cada dispositivo por la red local. La Shelly Wall Display XL hace dos papeles: es el punto único de control en la pared y la pasarela Bluetooth que recibe el sensor de movimiento y el pulsador de 4 botones.

Esquemas de conexionado

esquemas de principio; la instalación la valida un electricista autorizado
Fase L 230 V Neutro N +24 V CC 0 V / señal

Iluminación general · Dimmer Gen3

Usar luminarias LED marcadas como regulables y elegir corte de fase al inicio o al final en la configuración del dimmer si hay parpadeo. El pulsador de pared existente puede seguir funcionando en SW1.

Tira LED RGBW · Plus RGBW PM

Comprobar el consumo de la tira: W/m × metros ≤ 48 W (80 % de 60 W). La tira tiene que ser de 24 V para coincidir con la fuente. Con tramos largos, alimentar por los dos extremos.

Persianas · 2PM Gen3 en modo cortina

Un 2PM Gen3 por persiana (el 2PM usa sus dos salidas para un solo motor). Tras cablear: perfil "cover" y calibración. Nunca conectar dos motores en paralelo al mismo 2PM.

Campana extractora · 1PM Gen3

El 1PM da o quita alimentación a la campana; las velocidades se siguen eligiendo en su propio mando. La medida de consumo permite saber si está realmente aspirando y en qué velocidad (cada velocidad consume distinto).

Brazos TV abatibles · Shelly 1 Gen3

Opción A (brazo con entrada de pulsador): un Shelly 1 Gen3 por brazo; un pulso de 1 s abre o cierra. Opción B (motor 230 V de dos sentidos sin centralita): un 2PM Gen3 por brazo en modo cortina, igual que las persianas, y así la web sabe la posición.

Aire acondicionado · habilitación + consigna

El contacto apaga o habilita el equipo de forma fiable (cierre de aula, persiana abierta). Temperatura y modo no se controlan con un relé: necesitan el módulo Wi-Fi de la marca del aire o un emisor de infrarrojos con API local.

Wall Display XL y sensores Bluetooth

La pantalla se alimenta a 230 V (L y N) en una caja universal empotrada y su relé interno de 5 A queda libre: buena opción para un circuito on/off extra, como la luz de la isla o de la pizarra. El sensor BLU Motion y el pulsador BLU de 4 botones funcionan a pilas y se emparejan con la Wall Display, que reenvía sus eventos a la red. Colocar el sensor con vista a la zona de trabajo y lejos de fuegos y salidas de aire caliente.

  • Campana apagada (con retardo de 10 min)
  • Brazos TV recogidos

Cómo se comunica la web

el navegador nunca habla con los dispositivos directamente

El navegador llama a la API del servidor; el servidor traduce cada orden al protocolo del equipo y guarda las IPs y contraseñas. Así la web funciona igual desde la tablet o desde la Wall Display, y las credenciales no salen del servidor.

// Rutas del servidor (Node.js / Express)             → orden al dispositivo
POST /api/luz         { brillo: 0-100 }             → Dimmer   /rpc/Light.Set?id=0&on=true&brightness=…
POST /api/tira        { rgb:[r,g,b], blanco, brillo }→ RGBW PM  /rpc/RGBW.Set?id=0&rgb=[…]&white=…
POST /api/persiana/:n { pos: 0-100 | "abrir"|"parar"}→ 2PM nº n /rpc/Cover.GoToPosition?id=0&pos=…
POST /api/campana     { on: true|false }             → 1PM      /rpc/Switch.Set?id=0&on=…
POST /api/brazo/:n    { accion: "pulso" }            → 1 Gen3   /rpc/Switch.Set?id=0&on=true&toggle_after=1
POST /api/clima       { on, consigna }               → 1 Gen3 + API del fabricante del aire
POST /api/ptz/:n      { preset: 1-n }                → cámara   VISCA-IP "Memory Recall" o CGI del fabricante
POST /api/escena/:id                                 → lanza varias órdenes en paralelo
GET  /api/estado      (WebSocket)                    → Shelly.GetStatus de cada equipo, consumo de la campana

Para estados en tiempo real, el servidor puede abrir un WebSocket con cada Shelly (ws://IP/rpc) y reenviar los cambios a la web, de modo que si alguien pulsa un botón físico la página se actualiza al instante. Alternativa sin programar el servidor: Home Assistant con la integración Shelly, cuyo panel también se puede mostrar en la Wall Display XL.

Datos a confirmar antes de comprar o cablear

  • Cantidades: la lista no indica unidades. Hacen falta dos 2PM Gen3 (una por persiana) y, para los brazos, dos Shelly 1 Gen3 o dos 2PM según el tipo de brazo.
  • Brazos TV: marca y modelo; si llevan centralita con entrada de pulsador o un motor de 230 V directo.
  • Campana: potencia del motor y si tiene mando electrónico que se reinicia al cortar tensión.
  • Aire acondicionado: marca y modelo, si tiene bornes de ON/OFF remoto y módulo Wi-Fi con API local.
  • Cámaras PTZ: marca y modelo, y si admiten VISCA sobre IP o comandos HTTP para presets.
  • Tira LED: metros totales y consumo por metro, para confirmar que basta una fuente de 60 W.
  • Luminarias: que los downlights actuales sean regulables.
